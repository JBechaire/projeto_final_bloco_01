# 🧵 Chaveiros Josy – Projeto Final do Bloco 01  

Sistema de gerenciamento de produtos (chaveiros) desenvolvido em **TypeScript + Node.js** para o projeto final do Bloco 01 da **Generation Brasil**.

---

## 📌 Sobre o Projeto

Este é um sistema em **linha de comando (CLI)** que permite:

- Cadastrar produtos  
- Listar produtos cadastrados  
- Atualizar produtos  
- Deletar produtos  
- Exibir informações do desenvolvedor  

Todos os produtos são armazenados em um array e manipulados através de um **controller**.

---

## 🧰 Tecnologias Utilizadas

- **Node.js**
- **TypeScript**
- **readline-sync**
- **Paradigma POO (Programação Orientada a Objetos)**
